# The Digital Beachhead

The official website of Jacob Harrison: **https://harrcoded.github.io**

A landing craft beaches, a tank rolls onto the sand, and the long-promised confetti button finally works. Click it (or the tank) and the tank fires a shell that bursts into confetti across the page.

## Files
- `index.html`: page content and the beach scene (inline SVG)
- `style.css`: layout, the dispatch card, and scene animations
- `script.js`: landing sequence, aiming, and the confetti/smoke effects (canvas)

No build step and no dependencies apart from two Google Fonts (Black Ops One, Special Elite).

## Run locally
Open `index.html` in a browser, or run `npx serve .` and visit the printed address.
